# Aplikasi-Manajemen

membangun aplikasi terminal berbasis dart untuk mencatat daftar tugas harian dengan pengingat berbasis waktu dan prioritas

# Struktur Folder

- `bin/main.dart`: file utama aplikasi
- `lib/storage.dart`: file untuk alokasi tempat penyimpanan data yaitu file json
- `lib/task.dart`: file untuk mendefinisikan kelas tugas/data
- `tasks.json`: file untuk menyimpan data tugas

# Fitur

1. Menambahkan tugas baru
2. Melihat daftar tugas
3. Menghapus tugas
4. Melihat pemberitahuan jika ada tugas yang sudah deadline
